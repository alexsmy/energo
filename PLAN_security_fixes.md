# Безопасность: статус исправлений

Аудит 27.11.2026 закрыт; файл описывает закреплённые решения.

## Что сделано

- Редиректы проверяются по схеме и хосту, приватные и link-local адреса запрещены,
  размер ответа ограничен (`scripts/lib/throttle.js`).
- `safeUrl` / `safeHttpUrl` отсекают `javascript:` и `data:` в клиентских модулях
  и при дедупликации; `check-release` блокирует опасные схемы.
- Уже собранная запись не перезаписывается данными из сети (`prev` сохраняет
  непустые поля). Подстрочное совпадение заказчика удалено.
- Мобильные телефоны маскируются автоматически: `scripts/lib/mask-phones.js`
  в коллекторе, логере и сборке; CLI `node scripts/mask-phones.js --check`.
- CSP, антифрейминг и `noindex` в страницах; SRI на CDN Leaflet; `referrer`
  ограничены; CSV-экспорты экранируют формулы.
- Actions в workflow зафиксированы по SHA, токен не попадает в командную строку;
  исследовательские логи и `entities.tsv` не публикуются на Pages.
- Аналитика работает через один WordPress-канал; секретов в репозитории нет.

## Проверки и ручные действия

```bash
node scripts/test-security.js
node scripts/mask-phones.js --check
npm run check:release
```
