# Оборудование для транспорта нефти и нефтепродуктов — исследование 25.11.2026

Тема: насосные агрегаты и НПС, компрессоры, подогреватели/печи, турбины и ГТУ/электродвигатели для нефтеперекачивающих станций, уплотнения, системы смазки и охлаждения; заводы-изготовители, ремонтные предприятия, НИИ и инжиниринговые компании.

Артефакт: `data/research-2026/new-oil-equipment.json` (батч `oil-equipment`, 20 организаций, все ИНН отсутствуют в `data/entities.tsv`).

## Метод и статус источников

- **Браузер:** первые вызовы `skill({id:"browser"})` и `tools.browser.tabs.open/list` завершились `permission.rejected` / `Unknown tool`; после системного обновления каталога браузер стал доступен, `tabs.list()` вернул один tab, через `fill` + `Enter` в поле поиска Google выполнено **5 запросов в режиме ИИ `udm=50`** (1500–2000 символов каждый, т.к. прямой `tabs.open` с длинным URL отклонялся лимитом 2048 символов — запрос вводился в поле поиска).
- **Google AI Mode:** 2 запроса дали развёрнутые ответы (шесть насосных предприятий; ремонт/уплотнения/НИИ/ТНН). 3 запроса (в т.ч. оба «слепых») ИИ отклонил стандартной формулировкой «Не удается дать ответ на этот поисковый запрос» — честно зафиксировано, данные по ним получены из DDG и сайтов.
- **websearch** — HTTP 402; `r.jina.ai` — 451. Использовались DDG HTML/lite, webfetch и браузер.
- **Независимые проверки:** ИНН/ОГРН/статус каждого юрлица сверены минимум с двумя агрегаторами (Rusprofile, Checko, RBC Компании, List-Org, Audit-IT, Saby, Kontur.Фокус) по DDG-запросу с номером ИНН. Профиль — по официальным сайтам (hms.ru, oilpump.ru, sverdmash.ru, villina.ru, uralgidromash.ru, nfthm.ru, eitec.ru, sealmex.ru, avtokomtg.com, germetika.com, phm-mash.ru, pumps.transneft.ru, giprotruboprovod.transneft.ru, niitnn.ru, diascan.ru) и Википедии.
- **Слепой список:** без подсказки нашими названиями собраны перечни по запросам «российские производители насосов для магистральных нефтепроводов и НПС 2025–2026», «НПВ насосы производитель завод магистральные нефтяные», «печи подогрева нефти...», «капитальный ремонт насосных агрегатов НПС...». Источники: fabricators.ru (28 производителей нефтяных насосов), wiki-prom.ru (35 насосных заводов с ОГРН), oilpump.ru, hms.ru, sverdmash.ru, energybase.ru. Локальное сравнение с `entities.tsv` дало 20 новых ИНН.

Итого по типам: **ОЕМ — 11, ремонт — 2, инжиниринг/НИИ — 7**.

- **Проекты 2025–2026 не найдены:** АО НПП «Адонис», АО «Уралгидромаш», ООО «НПФ ЭИТЭК» (конкретные контракты), АО «Гидромашсервис», ООО «ГК АвтокомТехнолоджи» (конкретные контракты).
