Источник: `data/research-2026/new-oil-transport.json`. Батч `oil-transport`, 27 организаций.
Все ИНН сверены с `data/entities.tsv` (колонка 14) — коллизий нет. Полные тексты трёх
детализированных запросов Google AI Mode (udm=50) — в `queries` JSON.

## Статус браузера и Google AI

- Первая попытка (до появления инструментов) — неуспешна: `skill({id:"browser"})` вернул
  `permission denied`, `search` по каталогу Code Mode не нашёл `browser.*`. Попытка зафиксирована.
- После обновления каталога браузер подключился (`tabs.list()` → `about:blank`, без
  `not_attached`/`disconnected`). Выполнены 3 запроса: короткий URL `google.com/search?udm=50&q=transneft`
  (длинный URL >2048 символов не принимается), затем `fill` текстом 1000–1500 символов в поле
  «Задайте вопрос» + Enter. Все 3 ответа получены полностью (режим ИИ, таблицы по организациям).
- DDG HTML (`html.duckduckgo.com`) дважды отдал капчу; `lite.duckduckgo.com` работал стабильно
  (капча появлялась только при 6 параллельных запросах — перешли на батчи по 3).
  Дополнительно: Wikipedia API, ЕГРЮЛ-агрегаторы, официальный каталог
  https://transneft.ru/sites/ с телефонами/адресами обществ. `websearch` не блокировался, не применялся.

## Исключено (с причиной)

### Филиалы и объекты без собственного ИНН — НЕ добавлять
- **Нефтеперекачивающие станции (МНПС/НПС), ЛПДС, БКНС, ГПС, РНУ, ЛПУМГ** системы
  «Транснефть» — структурные подразделения ОСТ, собственного ИНН не имеют. Закупки идут
  только от имени юрлиц-операторов.
- **Нефтебаза «Усть-Луга»** — филиал ООО «Транснефть - Балтика», КПП 470743001, без ИНН.
- **«ЧелНУ — филиал АО «Транснефть-Урал»**, «Ленское РНУ» ООО «Транснефть-Восток»,
  филиал АО «КТК-Р» в Москве — филиалы с родительским ИНН.
- **Отдельные компрессорные/насосные станции и терминальные площадки** как самостоятельные
  карточки — не юрлица (аналогично решению по газовым КС, п. 28 AGENTS.md).

### Не существующие / неточные названия
- АО «Транснефть-Волга» — нет в ЕГРЮЛ; это «Транснефть-Приволга» (6317024749) или
  «Транснефть - Верхняя Волга» (5260900725).
- АО «Транснефть-ДФО» — нет; действует ООО «Транснефть - Дальний Восток» (2724132118).
- АО «ГТ Транснефть» — нет; вероятно АО «Гипротрубопровод» (7710022410) — добавлено под этим ID.
- АО «Транснефть-Центр» — нет; ЦФО обслуживают Верхняя Волга и Дружба.
- «Новороссийский терминал» — нет точного юрлица; есть Черномортранснефть, НМТП, АО «ТНТ».
- АО «МНПС» — в группе нет; МНПС = магистральные нефтеперекачивающие станции без ИНН.
  Единственное ЕГРЮЛ-совпадение — ОАО «Мамонтовнефтепромстрой» (8612001012),
  ликвидировано 22.06.2007, к «Транснефти» не относится.
- ООО «Транснефть-Терминал» ИНН 2315139909 — одноимённое юрлицо без тендерной активности;
  добавлять не рекомендуется (риск путаницы с АО «ТНТ» 2315143060).

## Рекомендация по переносу

При добавлении в `entities.tsv` начать с 10–12 ключевых юрлиц (холдинг + Дружба, Урал,
Сибирь, Верхняя Волга, Приволга, Север, Прикамье, Западная Сибирь, Черномортранснефть,
Балтика, Козьмино) и трёх сервисных (НИИ Транснефть, Диаскан, ТНН), затем расширять
терминальными операторами. Поле `tech` для них — `gpu` НЕ подходит; нужен новый код
типа (`oil_pipeline`/`oil_terminal`) в `js/tech-types.js` либо пустое значение.
Данные о закупках/ЭТП стоит перепроверить по свежим извещениям ЭТП ГПБ и Сбербанк-АСТ
перед добавлением в `tender-enterprises.json`.
