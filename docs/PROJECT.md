# Реестр предприятий РФ — 2026

Справочник предприятий и закупок: холдинги, юрлица, станции, ремонтные и инжиниринговые
компании, энергетика, машиностроение, авиация, судостроение, нефть и газ.

**Сайт:** https://alexsmy.github.io/energo/index.html ·
**Код:** https://github.com/alexsmy/energo

В каталоге 626 записей: 38 холдингов, 258 юрлиц и 330 станций. Все записи проверены.
Короткая инструкция — `docs/QUICKSTART.md`.

## Что умеет

- Три вкладки: **Реестр**, **Закупки**, **Карта**. Над реестром — шесть плашек-фильтров
  (все, холдинги, юрлица, станции, ремонтные, ОЕМ).
- Живой поиск по названию, реквизитам, контактам, руководителям и оборудованию,
  с подсказками. Фильтры по региону, типу оборудования, способу закупок и ЭТП.
- Карточки и таблица; сортировка по структуре, названию, региону и типу турбин.
  Порядок записей одинаков в обоих видах.
- Карта со слоями «Карта / Спутник / Гибрид», кластерами и переходом к полной карточке.
- Вкладка «Закупки»: 546 объявлений из открытых источников, аудит 16 ЭТП, поиск по
  ключевым словам и предприятиям с учётом словоформ, карточки и таблица.
- Избранное, экспорт CSV для Excel, печатная версия и PDF, журнал сбора.
- Автообновление: страница сама сообщает о новой версии и перезагружается через 5 секунд,
  сохранив фильтры и вид.

Аналитика посещений описана отдельно — `docs/VISITOR_ANALYTICS.md`.
Спецификация серверного плагина — `docs/ENERGO_VISITS_PLUGIN.md`.

## Как запустить локально

```bash
node build.js
python -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/index.html
```

Файлы `file://` не годятся для карты — нужен локальный сервер.

Печатная версия:

```bash
chrome --headless=new --no-pdf-header-footer --virtual-time-budget=9000 \
  --print-to-pdf=Энергореестр-РФ-2026.pdf http://127.0.0.1:8765/print.html
```

## Структура

```
index.html          интерфейс; print.html  печатная версия
log.html            журнал сбора;  archive.html  архив снимков
css/                экранные стили и стили A4
js/                 интерфейс, сортировка, закупки, карта, аналитика
data/entities.tsv   ручной источник реестра (31 поле, разделитель |)
data/plants.tsv     станции;  geo.js  координаты
data/tender-*.json  ключевые слова, предприятия, настройки сбора
scripts/            сбор закупок, парсеры площадок, проверки
build.js            сборка data.js, CSV, JSON и version.json
wp-plugin/          плагин WordPress «Energo Visits»
PLAN_*.md           статусные заметки, не активные планы
```

`js/data.js`, `js/tenders-data.js`, `registry.csv`, `registry.json` и `version.json`
создаются сборкой и вручную не правятся. Корневой `README.md` намеренно не создаётся.

## Закупки

Сбор идёт по расписанию через GitHub Actions из шести прямых парсеров площадок,
ГосПлан API (ЕИС), агрегатора GenTender и резервного HTML-парсера. В API уходит
опорное слово, а составная фраза проверяется локально по названию — это убирает
случайные совпадения. Все запросы пишутся в журнал, старые данные при ошибке не
удаляются. Ключевые слова меняются скриптом `node scripts/keywords.js`,
настройки сбора — `data/tender-settings.json`.
