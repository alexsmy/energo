# Как пользоваться приложением

Откройте https://alexsmy.github.io/energo/index.html — данные обновляются сами,
ничего запускать не нужно.

## Три вкладки

- **Реестр** — предприятия, холдинги, станции и заводы.
- **Закупки** — найденные объявления и проверка площадок.
- **Карта** — те же объекты на карте.

## Реестр

1. Плашки «Все / Холдинги / Юрлица / Станции / Ремонтные / ОЕМ» — быстрый фильтр.
2. Кнопка «Фильтры» открывает выбор по региону, оборудованию, способу закупок и ЭТП.
3. Поиск ищет по названию, ИНН, телефонам и руководителям. Слова можно вводить
   в начальной форме: «лопатка» найдёт и «лопатки».
4. Клик по карточке открывает полные реквизиты и контакты; звёздочка добавляет
   в избранное (счётчик — в шапке).
5. «Карточки / Таблица» и выпадающий список сортировки меняют вид списка.

## Закупки

1. Режимы «Действующие / Завершённые» и вид «Карточки / Таблица».
2. Ключевые слова разделены на базовые и составные; на телефоне группы
   переключаются кнопками. Нажмите слово — останутся подходящие закупки.
3. Поле «ключевое слово или заказчик» ищет и по предприятиям реестра.
4. Клик по закупке открывает карточку: заказчик, срок, цена, площадка и причина
   попадания в выборку. Оттуда можно перейти к организации или на площадку.
5. «Аудит ЭТП» показывает, где есть публичный поиск.

## Карта

- «Карта / Спутник / Гибрид» — подложки; «Показать всё» — все объекты.
- Фильтры открываются кнопкой в строке карты. Клик по маркеру даёт короткую
  карточку, оттуда можно открыть полную.

## Полезное

- «Экспорт CSV» — выгрузка в Excel; «Печать / PDF» — печатная версия.
- «Журнал сбора» внизу показывает источники данных. Если страница сообщит
  об обновлении, дождитесь отсчёта — фильтры сохранятся.
