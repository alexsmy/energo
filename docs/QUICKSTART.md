# Как пользоваться приложением

Откройте сайт: https://alexsmy.github.io/energo/index.html

Это справочник предприятий и закупок. Всё обновляется само, ничего скачивать и запускать вручную не нужно.

## Три вкладки вверху

- **Реестр** — карточки предприятий, станций, заводов и холдингов.
- **Закупки** — найденные объявления и проверка площадок.
- **Карта** — те же предприятия на карте.

## Реестр

1. Плашки «Все / Холдинги / Юрлица / Станции / Ремонтные / ОЕМ» — быстрый фильтр по типу.
2. Слева в «Фильтрах» можно сузить по региону, типу оборудования, способу закупок и площадке.
3. Строка поиска ищет по всему: названия, ИНН, телефоны, руководители, города, ЭТП.
4. Нажмите на карточку — откроется полная карточка с реквизитами и контактами.
5. «Карточки / Таблица» — переключение вида. Сортировка — выпадающий список вверху справа.
6. Звёздочка добавляет карточку в избранное (кнопка со звёздочкой в шапке).

## Закупки

1. Вверху режимы «Действующие / Завершённые» и вид «Карточки / Таблица».
2. Ключевые слова разделены на две группы: **Базовые слова** (турбина, лопатки, уплотнения, вставки, напыление, порошковые) и **Составные запросы** (например, «Ремонт турбины»). На телефоне группы переключаются кнопками.
3. Нажмите слово — останутся только подходящие закупки. Нажмите ещё раз — фильтр снимется.
4. Клик по закупке открывает подробную карточку: заказчик, срок, цена, площадка, причина попадания в выдачу.
5. «Прямой поиск на площадке» внизу открывает поиск на самой ЭТП с уже подставленным запросом.
6. «Аудит ЭТП» показывает, какие площадки доступны без регистрации и где есть публичный поиск.

## Карта

- Слои «Карта / Спутник / Гибрид» — переключение подложки.
- «Показать всё» — показать все объекты.
- Клик по маркеру открывает короткую карточку, оттуда можно перейти в полную.

## Полезное

- «Экспорт CSV» — выгрузка реестра в Excel.
- «Печать / PDF» — печатная версия всей книги.
- Ссылка «Журнал сбора» внизу показывает, когда и откуда пришли данные.
- Если открытая страница сама сообщит об обновлении — просто дождитесь отсчёта, она перезагрузится с новыми данными.

## Главное правило

Поиск работает по словам в начальной форме: «лопатка» найдёт и «лопатки», и «лопаткой». Сложные фразы проверяются локально по названию закупки, поэтому лишние совпадения отсекаются автоматически.
