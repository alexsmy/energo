# Закупки: статус контура сбора

Документ фиксирует текущее состояние сбора, а не план работ.

## Что работает

- Источники по приоритету: шесть прямых парсеров (`tektorg-direct`, `etpgpb-direct`,
  `roseltorg-direct`, `rad-direct`, `fabrikant-direct`, `zakazrf-direct`), ГосПлан API
  (ЕИС 44/223/615), GenTender (обход по ИНН), резервный `eis-html`.
  Старые SSR-адаптеры остаются для A/B через `--source=…`.
- В выдаче 546 закупок. В API уходит опорное слово; составная фраза проверяется
  локально, что убирает случайные совпадения. 8 базовых слов и 4 составных
  хранятся в `data/tender-keywords.json`.
- Покрытие: 294 ИНН организаций, 207 предприятий в `data/tender-enterprises.json`.
  `--dry-run` даёт 590 запросов в день, по понедельникам ещё 294, максимум 884 в неделю.
- Расписание: `tenders-update.yml` каждые 15 минут 05:00–15:45 МСК и 19:00 МСК,
  плюс ручной запуск; `ensure-daily.yml` проверяет результат и при необходимости
  dispatch'ит сбор. Гейт по `ran`/`date` закрывает день без сетевых запросов;
  `partial` разрешает не более двух попыток.
- Архив снимков (`data/archive/`) не в git; «новое» вычисляется сравнением
  с последним снимком. При ошибке сбора предыдущие записи сохраняются.

## Как проверять

```bash
node scripts/collect-tenders.js --dry-run      # план без сети
node scripts/collect-tenders.js --refilter --force  # пересопоставление без сети
node scripts/collect-tenders.js --probe-only  # только проверка доступности
npm run test:collect                          # тесты оркестратора
npm run test:direct                           # тесты парсеров на фикстурах
```

Журнал каждого запроса — `data/collect-log.json`, просмотр — `log.html`.
Настройки, бюджеты и глубина архива — `data/tender-settings.json`.

## Известные ограничения

- У B2B, RTS и AST нет публичного поиска: ссылки в аудите ведут на главную площадки.
- ГосПлан отдаёт 429 при частых запросах; обход по ИНН делает GenTender.
- Если площадка сменит параметр поиска, адаптер начнёт возвращать 0 записей —
  смотреть журнал. Доступность ЭТП проверялась 22.11.2026.
